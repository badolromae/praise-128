👥 투표 인원 (한 대결당)
시작하면 연결 안내와 QR이 나와요. 메인이 휴대폰·패드면 참가자는 메인의 핫스팟에, 메인이 노트북이면 같은 공유기 와이파이에 먼저 연결한 뒤 게임 QR을 스캔합니다.
📺 YouTube 로그인 (선택)
YouTube Premium 계정으로 로그인하면 게임 중 광고 없이 재생돼요. 로그인하지 않아도 게임은 그대로 진행됩니다.
📋 곡 목록 (복음성가)
총 0곡
📱 ① 와이파이(핫스팟) 연결 → ② 게임 QR 스캔
  1. 게임 화면을 띄운 메인 휴대폰·패드의 핫스팟을 켭니다.
    아이폰·아이패드: 설정 → 개인용 핫스팟 → '다른 사람의 연결 허용' / 갤럭시: 설정 → 연결 → 모바일 핫스팟
  2. 참가자 아이폰·아이패드는 설정 → Wi-Fi에서 메인 폰·패드의 핫스팟 이름을 눌러 먼저 연결합니다.
    아래 ① 와이파이 QR을 카메라로 찍으면 비밀번호 입력 없이 바로 연결돼요.
  3. 핫스팟 연결이 끝나면 카메라로 ② 게임 참가 QR을 찍어 게임에 들어옵니다.
  4. 참가자 화면 위쪽에 와이파이(또는 🔗 핫스팟) 표시가 떠 있는지 확인한 뒤 QR을 찍어 주세요.
  1. 노트북이 연결된 공유기 와이파이 이름을 확인합니다. (화면 오른쪽 아래 와이파이 아이콘)
  2. 참가자 폰·패드는 노트북과 같은 공유기 와이파이에 먼저 연결합니다. 아래 ① 와이파이 QR을 찍으면 바로 연결돼요.
  3. 와이파이 연결이 끝나면 ② 게임 참가 QR을 스캔합니다.
  4. 펜션·카페의 '게스트 와이파이'는 기기끼리 연결을 막는 경우가 있어요. 연결이 안 되면 노트북 핫스팟이나 휴대폰 핫스팟을 사용하세요.
